Preface

This book covers the first half of 208272 Elementary Statistics for Social Sciences II: the principles of statistical inference, inference about means, proportions and variances, and analysis of variance. All examples use economic contexts.

How to use this book

Each section of Chapters 2–4 matches one class session and follows the same pattern:

  1. Learning objectives
  2. Concept: why we need this method
  3. Formulas and conditions
  4. Example: a full solution
  5. Your Turn: a similar problem with space to write your own solution
  6. Reading R output (from Section 3.3 onward)
  7. Formula summary
  8. Exercises
  9. Solutions to Your Turn and the Exercises

In the PDF, the Your Turn problems have blank space for writing, and the solutions are at the end of each section. On the web, click a solution box to open it. Try the problem first.

Notation for critical values

The subscript of a critical value is the area to its left. This is the same convention as the R functions qnorm(), qt(), qchisq() and qf().

Notation Meaning R
\(z_{0.975}\) the \(z\) value with area 0.975 to its left qnorm(0.975)
\(t_{0.975,\,24}\) the \(t\) value with 24 df and area 0.975 to its left qt(0.975, 24)
\(\chi^2_{0.025,\,10}\) the \(\chi^2\) value with 10 df and area 0.025 to its left qchisq(0.025, 10)
\(F_{0.975,\,5,\,8}\) the \(F\) value with (5, 8) df and area 0.975 to its left qf(0.975, 5, 8)

The statistical tables for this course give the same left-tail areas:

Distribution Table Left-tail areas in the table
Standard normal (\(z\)) Table 4 \(z\) from 0.00 to 3.49
\(t\) Table 5 0.60, 0.70, 0.80, 0.90, 0.95, 0.975, 0.99, 0.995, 0.999, 0.9995
Chi-square (\(\chi^2\)) Table 6 0.0005 to 0.9995
\(F\) Table 7 0.90, 0.95, 0.975, 0.99, 0.995

A value calculated from the sample has the subscript “cal”, for example \(z_{\text{cal}}\), \(t_{\text{cal}}\), \(\chi^2_{\text{cal}}\) and \(F_{\text{cal}}\).

The five steps of a hypothesis test

  1. Hypotheses: state \(H_0\) and \(H_1\).
  2. Level of significance: state \(\alpha\).
  3. Test statistic: write the formula, substitute the values, and give the result.
  4. Critical value and critical region (Chapters 1–2 and Section 3.1), or the p-value (from Section 3.2 onward).
  5. Decision and interpretation.

Writing the conclusion

Decision using the critical region (Chapters 1–2 and Section 3.1)

\(t_{\text{cal}}\) = … [falls / does not fall] in the critical region (\(t_{\text{cal}}\) [<, >] …), so we [reject / accept] \(H_0\).

Decision using the p-value (from Section 3.2 onward)

p-value = … [<, \(\ge\)] \(\alpha\) = 0.05, so we [reject / accept] \(H_0\).

Interpretation

That is, … at the 0.05 level of significance.

  • If we reject \(H_0\), write \(H_1\) as a sentence.
  • If we accept \(H_0\), write \(H_0\) as a sentence.
  • For a two-sided test that rejects \(H_0\), also state the direction, using the sample statistic.

Confidence interval

We are 95% confident that … is between … and ….
